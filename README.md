# Klavye Altına Düşen Kırıntıların Bağımsızlık Bildirgesi

> Resmi açıklama: Bu depo bir şaka değildir.  
> Gayriresmi açıklama: Tamam biraz şakadır.  
> Hukuki açıklama: Kırıntı avukat tutmuştur.

## Bu nedir?

Klavye altına düşen ekmek, bisküvi, çekirdek kabuğu ve kimliği belirsiz un tanelerinin **uluslararası tanınma** sorununu çözen resmi yazılım.

Çalışır.  
Neden çalıştığını sormayın.  
Soranlar süpürgeyle görüştürülür.

## Kurulum

```bash
python3 bildirge.py
```

Başka bir şey kurmanıza gerek yok. Kırıntılar zaten kurulmuştur.

## Çıktı ne işe yarar?

- Diplomatik nota olarak kullanılabilir.
- Ev arkadaşına "ben temizledim" demeden önce okunabilir.
- Süpürgeye karşı delil niteliği taşır (mahkeme kabul etmeyebilir, kırıntı kabul eder).
